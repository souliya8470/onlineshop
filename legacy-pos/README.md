# legacy-pos/

**ໜ້າທີ່:** ໂຄດ POS ຕົ້ນສະບັບ — ຄັດລອກມາຈາກ `souliya8470/sykhai-pos` (v2.39) ຄຳຕໍ່ຄຳ, ຍັງບໍ່ໄດ້ແກ້ໄຂຫຍັງ.

**ເປັນຫຍັງມີໂຟນເດີ້ນີ້:** ຫຼັງຈາກ Tar ຕັດສິນໃຈວ່າລະບົບ SaaS ໃໝ່ຄວນອີງໃສ່ POS + ໜ້າຮ້ານອອນລາຍ ແທນ Marketing Studio (ຍ້ອນລູກຄ້າສົນໃຈໜ້າຮ້ານອອນລາຍຫຼາຍກວ່າ), ໄຟລ໌ນີ້ຖືກເອົາມາໄວ້ເປັນວັດຖຸດິບ (raw material) ສຳລັບການວາງແຜນໂຄງສ້າງໃໝ່.

**ສະຖານະ:** ຄັດລອກມາໄວ້ເທົ່ານັ້ນ — ຍັງບໍ່ໄດ້ຕໍ່ Vite, ຍັງບໍ່ໄດ້ວາງແຜນແຍກໂມດູນ. ລໍຖ້າໄຟລ໌ຕົ້ນສະບັບໜ້າຮ້ານອອນລາຍ (checkout.html/store.html/links.html/orders) ຈາກ Tar ກ່ອນ ຈຶ່ງຈະວາງແຜນໂຄງສ້າງໂຟນເດີ້ໃໝ່ທັງໝົດ (ຮ່ວມທັງ POS ແລະໜ້າຮ້ານ) ຄັ້ງດຽວ ແທນທີ່ຈະວາງເທື່ອລະສ່ວນ.

**ໝາຍເຫດ:** `souliya8470/sykhai-pos` ຜູກ `SHOP_ID` ຄົງທີ່ໄວ້ໃນໂຄດ (ຄືກັນກັບບັນຫາທີ່ Marketing Studio ມີ) — ຈະຕ້ອງແກ້ໃຫ້ອ່ານ shop_id ຈາກຜູ້ທີ່ login ແທນ ຕອນເຮັດເປັນ multi-tenant (ເຟດ 3).
